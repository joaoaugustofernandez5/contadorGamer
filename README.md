O aplicativo possui:
* contador de pontos;
* botão de aumentar;
* botão de diminuir;
* botão de resetar;
* interface estilo gamer.

--- 

# Tecnologias utilizadas 

* React Native 
* Expo 
* JavaScript

--- 

# Como executar o projeto

## 1. clonar o repositorio
```
git clone https://github.com/joaoaugustofernandez5/contadorGamer.git
```

## 2. Entrar na pasta do projeto 
```
cd contadorGamer
```

## 3. Instalar dependencias
```
npm install
```

## 4. Rodar o projeto
```
npm start
```
